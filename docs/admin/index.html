OWNER WORKSPACE

사이트 관리

PISTCO 계정으로 GitHub에 로그인해 관리합니다.
초안을 저장해도 공개되지 않습니다. ‘게시’ 작업을 실행해야 홈페이지에 반영됩니다.

01 / PROFILE

소개·연구 편집 ↗

이름, 소개와 연구 분야를 한국어·영어로 수정합니다.

 02 / PROJECTS

프로젝트 편집 ↗

프로젝트 추가·수정·삭제, 순서와 이미지 연결을 관리합니다.

 03 / MEDIA

이미지 업로드 ↗

JPEG·PNG·WebP, 파일당 10MiB 이하. 업로드 후 프로젝트의 image 필드에 파일명을 연결하세요.

 04 / PREVIEW

미리보기 생성 ↗

Run workflow → main을 선택합니다. 완료된 작업의 preview 파일을 내려받아 로컬에서 확인하세요.

 05 / PUBLISH

게시 실행 ↗

현재 초안 전체를 공개합니다. Run workflow에서 확인란을 선택하고 실행하세요. 배포 완료까지 잠시 걸립니다.

 06 / GUIDE

편집·복구 안내 ↗

파일 작성 예시, 이미지 교체, 게시 결과와 이전 버전 복구 방법을 확인합니다.

공개 전에 확인하세요

프로젝트에 연결한 이미지와 작성한 내용은 게시 시 공개됩니다. 사용하지 않은 이미지와 초안 원본은 비공개 저장소에 남습니다. 공개한 자료는 Git 이력이나 방문자가 저장한 사본에 남을 수 있습니다.

이 안내 화면은 누구나 볼 수 있지만, 연결된 작업실과 작업 실행 권한은 GitHub에서 제한합니다. 별도의 비밀번호나 토큰을 이 페이지에 입력하지 않습니다.
